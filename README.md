
# GEMILANG — TeamFlow

Aplikasi manajemen proyek dan kolaborasi tim berbasis web untuk membantu mengelola proyek, tugas, deadline, dan progres pekerjaan secara terstruktur.

## 🖥️ Application Preview

Berikut adalah hasil render UI aplikasi GEMILANG:

![GEMILANG UI Preview](gemilang-frontend/public/images/screenshot/satu.png)

## ✨ Features

- Project Management
- Task Management
- Deadline Tracking
- Team Collaboration
- Project Progress Dashboard

## 🛠️ Tech Stack

- Frontend: React
- Backend: NestJS
- Authentication: JWT
- Communication: AJAX
- AI Integration
- Deployment: Web Deployment

## 🚀 Getting Started

Clone repository:

```bash
git clone <repository-url>
cd <project-directory>
```

Install dependencies:

```bash
cd gemilang-frontend
npm install
```

Run the development server:

```bash
npm run dev
```
